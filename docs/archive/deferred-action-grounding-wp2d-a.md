# Deferred Action Grounding WP2D-A: strategy and complete obligation correspondence

WP2D-A adds an isolated, read-only grounding controller for an actually admitted ActionGoal v2. The deferred-action architecture and semantic-fidelity addendum are authoritative. This package prepares a fully accounted current target/operation/argument proposal; it executes no authored action and produces no successful-action witness, trace, compiled artifact, replay result or QA verdict.

## Changed boundary

`app/domain/action-grounding-strategy.ts` introduces the next unused M7 decision version, `decisionVersion: "5"` (versions 3 and 4 remain separate). Its closed `ground` decision contains the goal ID, a reviewed operation, and a total correspondence array. Each entry retains the **entire unchanged accepted obligation**, not just an ID or a paraphrase, plus one closed realization: effect, demanded operation, literal, exact role/name, independently endorsed semantic role, exact owned label, uniqueness, or pending. `stop` is separately closed and typed. No locator, CSS, XPath, JavaScript, current ref, executable DOM value or approval flag is accepted in this model contract.

`app/interpretation/action-grounding-controller.ts` adds `prepareActionGoalGroundingV1` and two adapter interfaces. Both adapters receive explicit fixed prompt versions and generated closed output contracts. The primary model can see the admitted source and prior bounded grounding outcome. Mechanical preflight rejects changed/omitted obligations, ownership substitutions and malformed mapping provenance before an independent call or browser query.

Semantic role translation (for example authored `dropdown` to reviewed `combobox`) and context-to-label inference require a separate source-first `mappingExtractionVersion: "1"` extraction. That extractor receives the original full instruction, immutable accepted goal/accounting/obligations, admission/handoff and reviewed vocabulary. It receives **no primary decision/correspondence, candidate, browser state, snapshot, selected ref, or retry reason**. Deterministic canonical comparison requires strict agreement of the complete correspondence; IDs are already stable admitted IDs. There is no majority vote, repair loop, older-format fallback or caller/model `approved` flag.

The mapping authority is an immutable in-process object issued through a private WeakSet after source validation and required independent agreement. Its digest links the exact WP1 handoff, goal, complete mapping, independent extraction digest, vocabulary version and the actual fixed primary/independent prompt versions. A serialized object or recomputed digest cannot recreate that authority. Correlated semantic model error remains probabilistic; browser facts cannot certify English meaning.

## Source realization and runtime composition

Label predicates retain exact source provenance. A designation uses its complete authored text. A context may propose a bounded exact contiguous `sourceSpan` within its accepted source-segment ownership; this supports a single retained context segment such as `using the Country dropdown` mapping to an exact authored `Country` occurrence **only after independent endorsement**. Deterministic code checks bytes, UTF-16 boundaries, ownership and complete span coverage. Without a span, referenced segments must be adjacent and retain every intervening byte. No English regex, synonym table, preposition authority, source trimming or word-specific patch chooses the label text. Nonliteral accepted obligations retain their existing multi-span provenance.

The additive `ActionCandidateGroundingSessionV1.prepareGrounding` method composes existing WP2A/WP2B/WP2C semantics under the existing exclusive lease. It requires the actual trusted mapping tied to the runtime's admission and an exactly issued complete WP2A parent. The parent request must equal the mechanical projection of the total correspondence. Authored exact role/name predicates remain in that parent; endorsed semantic-role and label realizations remain an explicit overlay rather than a silently rewritten old candidate predicate.

The runtime renews **every original broad-domain candidate and actual node**, evaluates complete owned-label facts across that domain using WP2C's existing isolated native/IDREF semantics, and intersects only reviewed source-linked predicates. It proves the full conjunction has one current visible/enabled compatible control; fill also requires editability. Unsupported or incomplete association semantics stop rather than disappear from the count. A browser-discovered name, convenient option, partial list or unendorsed relation cannot narrow the domain.

For native choice, uniqueness of the source-constrained control is proved before options are read. The existing WP2B isolated native option collection/getters prove complete ownership, displayed labels, values, disabled and selected states. Exact authored choice must match one enabled option, whose runtime-derived DOM value occurs uniquely in the entire owned collection. The composition owner ID is private to the new prepared strategy; it is **never issued as an old WP2A binding**. A Country label can narrow a broad two-dropdown domain, then its owned native option supplies the value. Two otherwise eligible controls remain ambiguous even if one convenient control contains the requested option.

Control and label-source identities are renewed again after option reads, including same-markup replacement checks. Owned option identities/order/facts are also renewed, and unchanged frame/page/state/session and inherited expiry are checked before recording. Existing browser helper limits, all-frame completeness and error semantics remain unchanged; no new browser primitive is introduced.

## Prepared contract and stops

`PreparedActionGroundingV1` is a distinct `status: "prepared", executed: false` record, with no action callback or locator. It preserves full source goal/instruction, total correspondence, exact admission/mapping/version links, original complete candidate observation, complete label association sets/source owners, complete native option facts and exact choice/value mapping when applicable, selected ref/frame, operation and inherited timing/provenance. Pending material is an empty list only after every mapping is valid and all required runtime predicates/arguments are proved. Relationships, spatial semantics, arbitrary containment, exclusions, references, prerequisites and custom controls remain unsupported/pending.

The parser mechanically validates source representation, total IDs and unchanged source obligations, mapping digest, complete candidate integrity, full-conjunction cardinality/membership, association count/list/source ownership and name metadata, argument purpose/text, option ownership/uniqueness/value mapping, and time bounds. Integrity parsing does not grant runtime origin: `protectedPreparedGrounding` must match the session's private journal. `protectedGroundingMapping` retains the actual immutable mapping authority separately for future trusted composition. Both are preparation readback, not a detached action capability.

The controller permits at most three attempts, a 45-second overall budget, eight seconds per model call, and 65,536-character input/output bounds. Each stale/query/busy retry starts a new model decision and **new complete query and composition**; cached refs/facts are not reused. Required independent inference is checked again. Mechanical/semantic mistakes are not autonomously repaired. Structural, semantic disagreement, unsupported/pending, unresolved cardinality/option/actionability, and provider/environment stops remain distinct non-QA outcomes. Disabled choice has the specific unresolved `OPTION_DISABLED` stop. Model errors/timeouts and exhausted stale retries are provider/environment stops.

No production workflow selection, provider transport, public-browser authority or credential flow changes.

WP2D-B must retain the actual WP1 admission and trusted total mapping authority, the complete prepared correspondence/source links, and matching private runtime readback. It must introduce a distinct reviewed execution seam that **freshly renews the entire conjunction, node/source/option identity, uniqueness, capability and source argument/value mapping inside the exclusive lease immediately before the action**.
