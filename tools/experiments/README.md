## Fixed-input workflow

From the repository root, build once with `npm run build`. To prepare a fresh trace, run one explicit provider-free `freeze` attempt of `semantic/grounding/semantic-grounding-v1-test-fixture-stability.mjs`; its output names the artifact root. Point `SEMANTIC_GROUNDED_TRACE_ARTIFACT` at the complete JSON under `semantic-grounded-trace-v1/<TestSpec ID>/<attempt ID>.json`. The compiler default preflight authenticates that exact file without opening a browser. Replay fixture preparation takes the same input and reports a Resolved v10 artifact path; the readback verifier additionally requires `SEMANTIC_RESOLVED_V10_ARTIFACT`.

The D1 scripts still compare D1/G1/R1 to the original experiment constants. A newly prepared fixture must satisfy those constants; a mismatch stops the experiment and must not be overridden by editing product contracts. The artifact paths are local, private inputs and should not be included in stakeholder-safe outputs. These tools do not bypass production public-target admission: their provider-free path uses explicit test-only fixture admission and intercepted local browser responses.

Reports retain their original conclusions and are indexed under [experiment evidence](../../docs/experiments/README.md). Superseded investigations are under [historical documentation](../../docs/archive/README.md).
